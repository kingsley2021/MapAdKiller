# MapAdKiller / MapClean 2.2.6（versionCode 2260）

发布日期：2026-10-27。版本码：2260。基线 v2.2.5-step2（版本码 2252）。

## 工具宫格

- **改用高德原生宫格**：关闭自绘（`SELF_DRAW_TOOL_GRID=false`），不再自己画图标和文字。
- **槽位上限修正为 10**（2 行 x 5 列）。官方 prefs `local_tool_list_for_xml_v2` 在真机上会写出 11 个 `id<i>`，
  第 11 个会被宿主挤成第三行，直接压到下面的「回家 / 去单位」行上 —— 这是「轻微重叠」的第一层原因。
- **payload 只写官方字段**：`writeSlotItem` 按 `OFFICIAL_FIELDS` 白名单拷贝 15 个字段，
  不再夹带 `weight` / `label` / `tips` 之类的私有键。
- **空槽模板取自官方**：`emptySlotTemplate` 复制宿主自己那一条空槽，保证补齐的空位与官方一致。
- **第二行裁切修复**：真机实测（1440x3200 / 560dpi）行 2 的格子宽 142 px、高只有 125 px，
  圆形图标上沿被切平。原因是宿主把每个格子塞进「行」`DtLinearLayout` 里，行的实测高度比格子内容矮 17 px，
  而 `clipChildren` 默认为 true。修复：宫格根 + 每个「行」`setClipChildren(false)` / `setClipToPadding(false)`，
  第 2 行起补 `topMargin = 10dp`（@560dpi = 35 px）。修复后行 2 图标 142 x 142，行距由 15 px 增至 33 px。

## 设置家 / 设置单位 / 常去地点

- 不再自绘，直接复用高德首页那一行原生 chip（`AmapNativeHome` 原样保留宿主 View，只做可见性映射）。

## 开关调整

- 删除「关闭首页「去XXX 打车」打车浮窗（打车运营卡）」与「显示「去哪里打车」卡片」两个开关。
  两个 key 的后端仍保留，但界面已无任何入口，等同永久关闭。

## 版本显示

- 设置页顶部的版本徽标原先固定显示「定制版」，现改为显示真实版本号（`v2.2.6`），
  有新版时显示 `v2.2.6 → vX.Y.Z`；内置版页脚同步改为 `MapAdKiller v2.2.6 · 免 root 整合版`。

## 首次使用与限制（务必提醒用户）

- **首次安装必须先抓一次官方下发数据**：装好后先把面板里的开关**全部关掉**，正常用一次地图（首页 / 搜索 / 我的），
  再退出重开，之后开关才会按设置生效。宫格、首页卡片、金刚位、底栏都是官方服务端下发的，不抓就没有数据。
- **首页工具宫格最多两行（10 个）**：超过会溢出，第三行会压到下方「回家 / 去单位」上，更多入口请用「更多工具」。

## 其它

- 铁律 0：首次安装 / 重装后先抓一次完整官方基线（`filesDir/baseline/<ver>/state.properties`），
  再启用模块功能，避免把模块改动后的状态当成官方状态。
- 免 root 内置版（LSPatch integrated）与本版同源同步，模块代码 4,470,136 B。
