# MapAdKiller 2.1.5

高德、百度地图广告精简与界面定制模块，基于 **libxposed API 102**，版本码 **215**。

**本版新增「免 root 内置版」**：把高德部分直接并入高德地图本体，不需要 root、不需要 LSPosed、不需要任何框架。腾讯地图保留原有实现，本轮没有重新验证。

## 下载

本版提供两个交付形态，按需要选一个即可（两者同一套源码，修复内容完全一致）：

| 形态 | 文件 | 适合谁 |
| --- | --- | --- |
| **免 root 内置版** | `AMap-2.1.5-rootless-integrated.apk`（约 191 MB） | **不想折腾框架**：直接安装就能用，不需要 root / LSPosed / 任何框架。只处理高德。 |
| **LSPosed 模块** | `MapClean-lsp-v2.1.5.apk`（约 4.1 MB） | 已经有兼容框架（libxposed API 102），需要同时处理高德 / 百度 / 腾讯。 |

⚠️ 免 root 内置版用 LSPatch 重新签名，**签名与官方高德不同**，因此不能覆盖安装官方高德：

- 从官方版换过来 → 必须先卸载官方高德，**会清除登录态与离线地图**；
- 已经是 2.1.3 / 2.1.4 免 root 内置版 → 可以直接覆盖安装，**不丢数据**。

⚠️ **安装时安全中心 / 病毒扫描报红是误报**，不是病毒。触发点有三个，全部来自重打包机制本身，无法通过"清理安装包"消除：① 包里内嵌了一个完整的 APK（`assets/lspatch/origin.apk`，即原版高德）；② 运行时从 assets 加载 dex；③ 内置签名绕过。自己用的话选「继续安装」或加入信任名单即可。**介意红标请用 LSPosed 模块版** —— 它不改动任何地图安装包，不会被报毒。

⚠️ 免 root 内置版体积较大（约 191 MiB），**下载后请先核对完整性**，不完整的包会报"解析软件包时出现问题"或"未签名"：

## 这一版解决什么

2.1.5 相对上一正式版 **2.1.2** 的变更，集中在四件“开关看起来没用”的事，以及新增免 root 交付形态。四项都在真机（高德 17.00.0.2005）上逐条验证过。

| 区域 | 功能与修复 |
| --- | --- |
| 百度地图 | **修复 2.1.4 的回归**：百度那一半根本没被转发到，一个钩子都没装（日志里连 `BMapClean` 都没有）。现在恢复转发，实测 60 个钩子全部装上。 |
| 免 root 交付 | 新增免 root 内置版：LSPatch 集成打包，内嵌原包与官方逐字节一致；入口是应用内悬浮球，不申请任何权限。 |
| 高德「设置家」 | 修复开关无效：那条行由高德自己绘制、模块只负责放行，而首页面板实例被高德缓存复用，改开关不会重建。现在**写完立刻生效**，并且默认开启。 |
| 高德工具栏 | 修复步行 / 骑行打开后不出现：高德自己的工具槽只有两项，模块以前只会删不会加。现在按“已开启”自动补齐空位（首页工具栏实测只有 5 格），且只改首页那一份数据。 |
| 高德工具目录 | 「更多工具」从「工具 → 其他」提到**「首页」分组**，有了独立开关，并在工具分类顶部说明 5 格上限。 |
| 高德地图标识 | 修复兴趣点开关完全无效：原生库在集成模式下的布局对不上、从未被加载，且原生侧把“没装成”报成了“装成了”。现在如实汇报（日志含 `framework_bound=`）。 |
| 高德首页 | 控制天气、扫街榜、活动、营销信息流、回家／公司等入口；数据刷新时继续应用规则。卡名解析改为按宿主真实规则。 |
| 高德底栏 | 同步入口列表、布局与点击目标，修复隐藏打车后误跳转及选中背景尺寸问题。 |
| 高德地点详情 | 为长按地图后的“发现好去处”照片信息流提供独立开关，保留地址和路线等操作。 |
| 百度首页 | 继续清理活动轮播、任务横幅、推荐流及 AI 此刻卡片。 |
| 百度底栏 | 同时重排可见按钮和原生透明点击区，修复点击“我的”进入打车的问题。 |
| 百度搜索 | 去除热度飙升榜、推广搜索词和推荐词标签，保留分类、常用地址、搜索历史与正常搜索。 |
| 两个地图的标识 | 整体控制兴趣点图标和名称，保留道路、城市及基础地理名称。 |
| 配置与框架 | 分组导入导出高德、百度及模块设置；完善 Vector 2.2 公开服务接口和状态显示。 |

另外「开关写入即生效」也一并改了：首页工具面板原地重建、原生样式过滤重新下发，不再需要“退出重进首页”。（地图标识对**已经渲染**的那份样式仍要重新进入地图页才完全生效，这是引擎缓存行为。）

## 免 root 内置版

**它是什么**：把模块的高德部分单独并入高德地图本体，得到一个不需要 root、不需要框架的独立 APK。安装后打开高德，界面右侧常驻一颗悬浮球，点开就是全部高德设置。

| 项 | 说明 |
| --- | --- |
| 适用地图 | 高德地图 **17.00.0.2005**（versionCode 170000） |
| 架构 | arm64-v8a / armeabi-v7a / x86 / x86_64 |
| 宿主处理 | LSPatch v1.2 集成模式；内嵌 `origin.apk` 与官方原包**逐字节一致** |
| 入口 | 应用内悬浮球，**不申请任何权限**（不是系统悬浮窗，退出高德即消失） |
| 不含 | 百度 / 腾讯的处理（代码在打包前就被删掉，不是运行时跳过） |

悬浮球支持拖动跟手、松手吸附到左右边缘、停靠后自动半隐藏；点边条可重新拉出。设置面板是玻璃质感的底部抽屉，分类为 首页 / 工具 / 内容 / 地图 / 我的 / 底栏 / 其他，顶部状态药丸实时显示是否可写入；**写入失败会自动回滚并提示**，不会出现“看起来打开了其实没写进去”的假状态。

安装：

```powershell
# 从官方高德换过来（会清除登录态与离线地图，请先备份）
adb uninstall com.autonavi.minimap
adb install "AMap-2.1.4-rootless-integrated.apk"

# 从 2.1.3 / 2.1.4 免 root 内置版升级
adb install -r "AMap-2.1.4-rootless-integrated.apk"
```

## 安装与设置

1. 安装 Release 中的 `MapClean-lsp-v2.1.5.apk`，已有用户可覆盖安装。
2. 在支持 libxposed API 102 的框架中启用模块，勾选需要处理的地图应用。
3. 进入模块设置，按地图和分组调整选项。
4. 修改后强制停止对应地图，再重新打开；地图标识样式在渲染器初始化时生效。

大多数开关以“显示”为语义：**开启显示，关闭隐藏**。工具栏的“仅显示已开启工具”是额外的列表模式：开启后，未选择和新下发的未知工具不再自动进入首页。

| 设置 | 开启后的行为 | 关闭后的行为 |
| --- | --- | --- |
| “显示……” | 保留对应入口或内容 | 隐藏对应入口或内容 |
| 工具栏总开关 | 应用工具列表设置 | 整个工具栏隐藏 |
| 仅显示已开启工具 | 首页只保留明确选择的工具 | 按普通模式处理工具列表 |
| “关闭……”或“去除……” | 启用对应去除规则 | 保留原应用行为 |

想只保留步行、骑行等工具时，先开启工具栏总开关，再开启“仅显示已开启工具”，最后选中需要的工具；需要继续进入完整目录时，请同时保留“更多工具”。**首页工具栏只有 5 格**，开第 6 个工具不会出现在那里——它仍在「更多工具」页里。工具栏总开关关闭时，单个工具的选择不会让工具栏重新出现。

地点详情的独立开关控制“发现好去处”标题和照片信息流，默认隐藏；“逛逛周边”快捷工具、地址、分享、收藏、新增与路线操作继续保留。这项设置针对地点详情，不代表导航规划中的所有业务卡片都已处理。

地图兴趣点标识默认隐藏。旧细分类别设置迁移到整体开关；道路、城市、河流等基础内容不属于兴趣点隐藏范围。搜索结果、收藏点和正在选择的位置可能作为业务图层继续显示。

“设置家 / 设置单位 / 常去地点”默认显示（它是地图核心功能，不属于推荐内容）。若不需要，在「首页」分组关掉即可，改动立即生效。

## 配置备份与迁移

设置中的“保存配置／恢复配置”用于本地备份；“更多 → 导出／导入”用于交换 JSON 配置文本。备份覆盖高德、百度及模块设置，导入后请强停对应地图并重新打开。

升级前建议先导出配置。旧版仅含高德的平面配置仍可导入，未包含的百度设置不会被重置；未知键会忽略，错误类型会提示失败。旧地图标识细分类设置会迁移到整体开关，迁移后可重新选择显示兴趣点。

2.1.4 会做一次一次性迁移（`_amap_protocol_schema` 210 → 211）恢复「设置家」的默认值；它只对“迁移前本来是开”的安装恢复，**不会覆盖你显式做过的选择**。

配置备份不包含地图账号、收藏、离线地图或框架作用域；更换设备后仍需在框架中重新勾选地图。恢复默认会重置模块选项，请先保存需要保留的配置。

## 适配范围

本轮主要实测 **高德 17.00.0.2005**、**百度 22.0.0（1650）**，测试设备运行 Android 16 与 LSPosed 2.1.1。免 root 内置版另在 Android 16 真机上完成覆盖安装与四项修复的逐条验证。

常规适配改为检查实际类、方法和数据结构，不再仅因地图版本号变化就关闭整套功能。仅在已知版本具有明确含义的混淆接口保留版本限制。目标接口变化时，相关功能回退到原应用行为；不代表任意未来版本都已验证。

Vector 2.2 使用官方 API／service／interface 102 依赖，模块状态查询异步执行，区分服务连接等待、作用域读取失败和未勾选地图，避免把连接等待误报为未激活。**本轮没有 Vector 2.2 实机测试环境**，兼容依据与检查范围见完整更新说明。

## 常见问题与反馈

**开关修改后没有变化？** 先确认模块已启用、对应地图在作用域内，再强停地图重开。地图标识设置需要重新初始化渲染器。检查工具栏总开关和“仅显示已开启工具”是否同时影响了列表。免 root 内置版的首页改动是立即生效的；地图标识同样需要重新进入地图页。

**刷新后又出现信息流，或点“我的”进入打车？** 2.1.2 已针对重复数据刷新与原生点击区重排修复。如果仍能复现，请提供地图完整版本号、隐藏的入口、工具模式以及连续操作步骤，便于区分不同界面的数据或路由变化。

**开了步行 / 骑行，首页工具栏还是不显示？** 首页工具栏只有 5 格，且优先保留高德自己的顺序。确认「首页 → 首页工具宫格」是开启的；如果格数已满，请关掉不需要的工具，或到「更多工具」页进入。

**免 root 内置版装不上 / 提示签名不一致？** 它是重新签名的包，必须先卸载官方高德。卸载会清除登录态与离线地图，请先确认可以接受。

**为什么还有部分图标？** 搜索结果、收藏、选点及导航提示可能使用独立业务图层。当前兴趣点开关处理底图兴趣点，同时保留道路、城市等基础地理名称。

**如何提交有效反馈？** 请在 [Issues](https://github.com/ldxm666/MapAdKiller/issues) 写明模块版本、地图版本与版本码、Android 版本、框架名称与版本、开关状态、复现步骤、实际和预期结果。高德可在“其他”页、百度可在“诊断”处启用日志：打开日志、重开地图、复现一次、提取相关框架日志后关闭日志。免 root 内置版可直接用 `adb logcat | grep -E "MapAdKiller|MapCleanLabels"`。公开前请遮挡账号、精确位置、路线、订单及令牌等信息。

## 构建

需要 JDK 21、Python、Android SDK 与 NDK；当前脚本使用 SDK Platform 34、Build Tools 35.0.0 和 NDK 26.3.11579264。按本机路径检查 app/build.ps1 和 app/native/build.py，然后执行：

    python .\app\native\build.py
    .\app\build.ps1

输出为 `output/MapClean-lsp-v2.1.4.apk`。原生库覆盖 arm64-v8a、armeabi-v7a、x86、x86_64，并检查 ZIP 存储方式与 16 KB 对齐。框架 API 仅参与编译，不打入模块 APK。

免 root 内置版由单独的打包脚本产出（精简源码 → 编译内嵌模块 → LSPatch 打补丁 → 校验发布）：

    python .\tools\build_variant.py --OriginalApk <官方高德 APK> --OutputDirectory output\nonroot-amap

脚本是 fail-closed 的：内嵌 `origin.apk` 必须与官方原包逐字节一致、模块哈希必须匹配、四个 ABI 的原生库必须齐备，任何一项不过就直接失败，不会产出半成品。

**产物只能保留 LSPatch 自己的 v2 签名，这不是包坏了，而是包内有意嵌套**：`assets/lspatch/origin.apk` 是原封不动的官方 APK，而官方 APK 自身的条目（`lib/*.so`、`assets/*`、`resources.arsc` 等）也仍在包里，字节**物理上就位于 origin.apk 覆盖的那段区域**。于是统计各条目声明大小之和会得到 366 MB（文件只有 200 MB），`zipalign -c` 会报一批 "header mismatch"，而任何按声明大小重建的工具都会把原区域复制两遍、把产物撑到 367 MB。Android 与 Python 的 zipfile 都读本地头，因此完全正常 —— `adb install` 与 MIUI 安装器均实测可装、应用可正常运行。

连接开启 USB 调试的测试设备后，可运行 `.\tests\run-android.ps1 -BuildDirectory .\app`。其中地点详情数据过滤测试已在 Android 的真实 `org.json` 上通过 136 项断言，覆盖布局引用清理、基本信息保留、重复响应和未知结构回退。
